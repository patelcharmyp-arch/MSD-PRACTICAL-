# MSD Practical

This repository contains practical implementations for Modern Software Development (MSD) covering Practicals 1 through 13.

## Practical Overview

- **Practical 1** - React / Frontend basics
- **Practical 2** - React components and state management
- **Practical 3** - React forms and events
- **Practical 4** - React hooks and component lifecycle
- **Practical 5** - React routing and UI design
- **Practical 6** - Node.js & Express server setup
- **Practical 7** - Express & MongoDB integration (CRUD Operations)
- **Practical 8** - Express REST API development
- **Practical 9** - File upload handling with Multer & MongoDB
- **Practical 10** - Full Stack MERN Application (Frontend + Backend)
- **Practical 11** - User Authentication with JWT & Blog Management
- **Practical 12** - Full Stack Application with CRUD functionality
- **Practical 13** - Document Management System with File Uploads

## Setup & Running

For each practical folder:

```bash
# Navigate to practical directory
cd "practical <number>" # or Practical_<number>

# If it contains client & backend:
cd backend
npm install
npm start # or npm run dev

cd ../client
npm install
npm run dev
```

> **Note**: For backend practicals requiring MongoDB, copy `.env.example` to `.env` and fill in your connection string and credentials.
